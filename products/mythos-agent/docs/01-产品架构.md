# 产品架构

## 系统位置

```text
用户
  │ Interactive CLI / Headless / Web / Desktop
  ▼
Mythos Agent 产品层
  ├─ Product：启动、配置同一性、产品边界
  ├─ Agent Preset：persona、工具、压缩、委派、计划
  ├─ Evaluation：单轮、多轮、高级旅程、真实仓库评测
  ├─ Flywheel：归档、分析、筛选、回归门禁
  ├─ Release：冻结运行闭包、完整性清单、消费端验证
  ├─ Desktop：Electron 壳、受控路由、热配置、应用更新
  └─ Controller：战略决策、持久记忆、阶段复审
  ▼
DeepSeek Harness 0.1.0-rc.8
  ├─ Agent Loop / Session / Persistence
  ├─ Tools / Shell / Filesystem / Web
  ├─ Compaction / Goal / Plan / Subagent / Workflow
  └─ Web Client / CLI / API Gateway
  ▼
受控模型网关 + 飞轮数据源
```

Mythos Agent 不复制 DeepSeek Harness 能力。通用 agent 生命周期、会话、工具和 Web 客户端能力在上游包中演进；产品目录只拥有 Mythos 的组合、评测、飞轮、发布和治理策略，[`apps/desktop/`](../../../apps/desktop/) 拥有桌面交付壳。通用架构见 [`docs/architecture.md`](../../../docs/architecture.md)。

## 运行平面

### Headless

`pnpm --dir products/mythos-agent agent -- "<task>"` 通过 [`product/launch.ts`](../product/launch.ts) 启动已构建的 DSH CLI，并将 `DSH_HOME` 固定为产品自有的 [`home/`](../home/)。不带 surface 参数的发布 CLI 进入可恢复的交互式循环，首轮记录 session id，后续任务使用 `--resume`继续同一会话。

### Web

`pnpm --dir products/mythos-agent web` 使用 `mythos-web` Profile 启动 Web 产品面。产品固定 `mythos` Agent Preset，禁止用户根 Preset、模型选择和插件配置界面改变发布身份。

### Desktop

MYTHOS Desktop 是 Electron 托管壳，内置已验证的 Mythos 发布运行时，并以单个 loopback Host 提供 Web UI。桌面层选择受管 HTTPS 服务端点、隐藏模型与插件基础设施，从签名 manifest 原子激活热配置，并通过分层来源检查应用更新。Desktop 不重新实现 Agent 能力。

## 发布运行闭包

[`release/pack.ts`](../release/pack.ts) 从固定 lockfile 离线构建 Web 前端，部署 DSH 生产依赖，关闭工作区符号链接，清除嵌入随机 staging 路径的 shim，并将两个独立 staging 树归档为字节相同的 tar.gz。`release-integrity.json` 记录每个文件的模式、大小与 SHA-256，以及每个符号链接目标。

[`release/consumer.ts`](../release/consumer.ts) 在无仓库工具、无继承凭据的临时目录中校验、解压和运行发布包。它验证 Headless 配置、Web loopback 服务、必需静态资源、被禁 UI 插件的不存在、M3 工具交换、交互式恢复以及篡改拒绝。

## 配置与模型边界

- [`home/profiles/mythos/cordis.patch.yml`](../home/profiles/mythos/cordis.patch.yml) 定义 Headless 产品差异。
- [`home/profiles/mythos-web/cordis.patch.yml`](../home/profiles/mythos-web/cordis.patch.yml) 定义 Web 产品差异。
- [`home/.agent-presets/mythos/agent.cordis.yml`](../home/.agent-presets/mythos/agent.cordis.yml) 定义每个 Mythos agent 的模型可见能力。
- [`product/config.ts`](../product/config.ts) 检查两个 Profile 的模型、persona、Bundle 和 Agent Preset 不发生漂移。
- [`package.json`](../package.json) 固定 Mythos 版本与 DSH 版本、提交和上游地址。

当前产品 Profile 只公开 `mythos/claude-sonnet-5`，默认使用 high reasoning，通过受控 HTTPS 网关访问。`DEEPSEEK_API_KEY` 只由启动进程读取，Shell 工具不得继承密钥。产品模型身份变化必须同时更新两个 Profile、Preset、配置检查和评测 cohort。

## Agent Preset 能力

Mythos Agent Preset 当前组合文件系统读写与搜索、受控 Shell、Web 搜索、skill、目标、计划模式、待办、压缩、后台任务、subagent 与 workflow。通用服务保持在 Host 平面，每 agent 状态通过 Cordis isolate realm 隔离；不得为了产品便利复制一套进程全局 registry。

## 评测与飞轮数据流

```text
评测配置 + 用例 + DSH/Mythos 版本
  → 执行快照
  → 隔离工作区内真实 Agent 执行
  → 外部 verifier 验收
  → 原始会话 + label + 内容哈希
  → 归档与 cohort 分析
  → 发布门禁 / 数据筛选 / harness 改进
```

一个 cohort 由 DSH 版本、Mythos 版本、配置 SHA-256 和运行模式组成。配置、用例或运行时身份变化后，旧样本不得被计入新 cohort 的发布证据。

## 总控边界

[`control/`](../control/) 定义项目宪法、决策协议、持久记忆和周期复审。总控端口只允许记录决策、指导 Lead 以及暂停或停止项目运行，没有文件、Shell、工具或任务执行接口。当前该目录是可测的控制内核，不等于已经装配到 Headless 或 Web 运行时。
